# Michael's Cream

A small static recipe site for Ninja Creami Deluxe recipes.

## Publish on GitHub Pages

1. Upload all files in this folder to the root of the `michaelscream` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose **main** and **/(root)**, then click **Save**.
5. After deployment, the site should be available at:
   `https://midohubb.github.io/michaelscream/`

## Files

- `index.html` — recipe homepage
- `kids-vanilla.html`
- `kids-chocolate.html`
- `chocolate-pb-protein.html`
- `strawberry-cheesecake-protein.html`
- `style.css`
- `script.js`
- `.nojekyll`

Each recipe page includes Schema.org Recipe JSON-LD and a Cronometer-friendly copy block.
